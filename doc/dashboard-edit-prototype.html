Edit mode — size controls folded into the element pill (interactive mock)

Option 1 (pills + tabbed right panel). Instead of resize handles, the selected element’s pill unfolds into a connected second line with w and h − / + buttons: width = flex weight among siblings, height = minimum-height step (2h em). Click pills to select (views and containers), use the − / + buttons, the panel steppers (containers), or the keyboard (←→ width, ↑↓ height). Views are inert (hatched). Drag a pill to reorder: a blue insertion line shows where it will land, and you can drop into any container, empty ones included (Alt + arrows or the ◂ ▸ buttons in the panel also move it; Esc cancels a drag). In edit mode each container reserves a thin band at its top for its pill, so the pill can unfold without covering its children. Click empty space to select the dashboard.
