Help panel: sending data

What the panel should do

Show that sending data is one line, then let the user climb at their own pace to richer data (time, text, positions, 3D, point clouds, images). The user says how they send (a terminal over UDP, Python, C++, an Arduino on a serial port) and every example is written that way. The language switches of the mock-ups work: click them. The message itself is always in blue: it is the same in every language.

  • One line firstA number named and sent: nothing else is needed to see a chart.
  • ProgressiveSeven kinds of data in order of difficulty; the hard ones never stand in the way of the easy ones.
  • In my languageChosen once, remembered. Here: Terminal, Python, C++, Arduino; the list can grow.
  • To check before buildingThe C++ client only sends numbers today (the mock-ups say so where it matters), and each snippet has to be tested for real, as the examples of the current panel are.

7The playground

A field to type a message and send it to the page itself, no device needed; the chips fill it with an example of each kind. Under it, the same message as it would be sent from the chosen language.

Good for
Learning by doing in ten seconds, and a way to test a format before writing code.
Watch out
It is one more feature to build, and it teaches the text format rather than the client libraries.

10The checklist that fills itself

The ladder, aware of what the page has received: a step is ticked when a telemetry of that kind has arrived, with its name. The next step is open, the others folded.

Good for
Confirms each success and suggests the next thing to try; the progress bar invites to go on.
Watch out
Game-like: an expert who only sends numbers sees "2 of 7" for ever. It needs an off switch or a quiet look.

Recommendation

1, the ladder, with the first step of 2 (the box that confirms the first value arrived) and the set-up line of 8 shown once above step 1. It keeps "one line" in view, orders the rest, and stays a plain list. 7 (the playground) is the most convincing for a first visit but is a feature of its own; 10 is the ladder taken one step further, to consider once the ladder exists.
